GitHub 연결

일정은 비공개 GitHub 저장소의 events.json에 저장돼요. 이 브라우저에서 한 번만 연결하면 계속 쓸 수 있어요. 토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지 않아요.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 데이터 저장소 하나만 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만든 토큰(github_pat_…)을 아래에 붙여넣기
